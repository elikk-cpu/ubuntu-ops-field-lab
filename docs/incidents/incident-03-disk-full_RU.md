# INC-03 — Нет свободного места на диске

## Статус
Устранён (контролируемый инцидент LAB 01).

## Окружение
- Сервер: ubuntu-ops-01
- Хранилище: виртуальные диски VMware, LVM, ext4
- Изолированная файловая система: /dev/loop0
- Точка монтирования: /mnt/lab01-inc03
- Размер файла-образа: 64 MiB
- Дата: 2026-10-14 (UTC)

## Симптомы
Попытка записи 70 MiB завершилась ошибкой:

No space left on device

Команда dd вернула код завершения 1.

## Диагностика
Изолированная файловая система ext4 показала:

- Полезная ёмкость: 56 MiB
- Доступно до ошибки: 52 MiB
- Доступно во время инцидента: 0
- Заполненность: 100%
- Свободные inode: 16371
- Размер тестового каталога: 52 MiB

## Первопричина (Root Cause)
Тестовый файл исчерпал доступные блоки данных
изолированной файловой системы ext4.

Проблема не была связана с нехваткой inode.

## Устранение
Удалён временный файл fill.bin.

Доступное пространство восстановилось до 52 MiB,
заполненность файловой системы снизилась до 1%.

## Проверка восстановления
- Создание нового файла: PASS
- Содержимое контрольного файла: recovery-ok
- SHA256 основного LVM: OK
- Файловая система успешно размонтирована
- Loop-устройство освобождено
- Временный образ удалён

## Профилактика и выводы
- Проверять заполненность через df -hT.
- Проверять inode через df -i.
- Искать крупные файлы и каталоги через du.
- Настраивать оповещения до заполнения диска на 100%.
- Изолировать временные данные и эксперименты.
- Проверять целостность данных после восстановления.
