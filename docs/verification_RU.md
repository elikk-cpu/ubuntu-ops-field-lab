# LAB 01 — Протокол проверки

## 1. Статус

Лабораторная находится в процессе выполнения.

Раздел разграничения файловых прав: 8/8 проверок пройдены.

Дата испытаний: 2026-10-12.
Источник времени: UTC, согласно evidence.

## 2. Исходное состояние

Сервер: ubuntu-ops-01
ОС: Ubuntu Server 24.04.5 LTS

Участники:
- ubuntu — администратор
- developer — участник группы app-developers
- operator — участник группы app-operators

Каталоги:
- /srv/ubuntu-ops/app
  Владелец: root
  Группа: app-developers
  Режим: 2770

- /srv/ubuntu-ops/reports
  Владелец: root
  Группа: app-operators
  Режим: 2750

Контрольный файл:
- /srv/ubuntu-ops/reports/sample-report.txt
  Владелец: root
  Группа: app-operators
  Режим: 0640

Проверяются стандартные файловые права Linux (DAC).
Обозначения ACL-01–ACL-08 являются ID испытаний,
а не расширенными POSIX ACL.

## 3. Проверки ACL-01–ACL-05

### ACL-01 — Создание файла разработчиком

Исходное состояние: developer входит в app-developers.
Проверка: создание dev-evidence.txt от имени developer.
Ожидалось: успешная запись и наследование группы.
Фактически: exit code 0; владелец developer;
группа app-developers; права 664.
Результат: PASS.

### ACL-02 — Запрет записи оператору в app

Исходное состояние: operator не входит в app-developers.
Проверка: создание operator-evidence.txt.
Ожидалось: Permission denied, файл отсутствует.
Фактически: exit code 1; file absent check 0.
Результат: PASS.

### ACL-03 — Запрет просмотра reports разработчику

Исходное состояние: developer не входит в app-operators.
Проверка: просмотр /srv/ubuntu-ops/reports.
Ожидалось: Permission denied.
Фактически: exit code 2.
Результат: PASS.

### ACL-04 — Просмотр reports оператором

Исходное состояние: operator состоит в app-operators.
Проверка: получение списка файлов каталога reports.
Ожидалось: успешный просмотр.
Фактически: exit code 0.
Результат: PASS.

### ACL-05 — Запрет создания отчётов оператором

Исходное состояние: группа app-operators не имеет
права записи в каталог reports.
Проверка: создание operator-evidence.txt.
Ожидалось: Permission denied, файл отсутствует.
Фактически: exit code 1; file absent check 0.
Результат: PASS.

Доказательства: [ACL-01–05](evidence/acl-01-05.txt).

## 4. Проверки ACL-06–ACL-08

### ACL-06 — Чтение отчёта оператором

Исходное состояние: файл root:app-operators, режим 0640.
Проверка: чтение sample-report.txt от имени operator.
Ожидалось: успешное чтение.
Фактически: exit code 0; содержимое прочитано.
Результат: PASS.

### ACL-07 — Защита целостности отчёта

Исходное состояние: operator имеет только право чтения.
Проверка: попытка дописать Modified в sample-report.txt.
Ожидалось: Permission denied; SHA256 не изменяется.
Фактически: exit code 2; SHA256 до и после совпал.
Результат: PASS.

### ACL-08 — Запрет чтения разработчику

Исходное состояние: developer не входит в app-operators.
Проверка: чтение sample-report.txt от имени developer.
Ожидалось: Permission denied.
Фактически: exit code 1.
Результат: PASS.

Доказательства: [ACL-06–08](evidence/acl-06-08.txt).

## 5. Выводы

Все восемь проверок файловых прав завершились
в соответствии с ожидаемыми результатами.

Подтверждены:
- разграничение доступа по группам;
- наследование группы через SGID;
- запрет несанкционированной записи;
- разрешённое чтение отчётов;
- сохранение целостности контрольного файла.

Права 664 на файле разработчика требуют отдельного
анализа umask. Доступ сейчас ограничен каталогом.

## 7. Проверка sudo-полномочий

Дата проверки: 2026-10-12.

Исходное состояние:
- ubuntu имеет полные административные sudo-права.
- developer не имеет sudo-полномочий.
- operator первоначально не имел sudo-полномочий.

Настроенная политика:
- operator может перезапускать ubuntu-ops-api.service от root.
- Общие права на systemctl или полный sudo не предоставлены.
- Файл sudoers принадлежит root:root, режим 0440.
- Общая проверка синтаксиса sudoers пройдена.

Результаты:
- SUDO-01: разрешение перезапуска API; exit 0; PASS.
- SUDO-02: перезапуск SSH не разрешён; exit 1; PASS.
- SUDO-03: разработчик не имеет права перезапуска API;
  exit 1; PASS.
- SUDO-04: произвольная команда root не выполнена;
  exit 1; PASS.

API-служба ещё не установлена. Проверено разрешение
команды в sudo, но не фактический перезапуск службы.

Доказательства: [Sudo policy](evidence/sudo-policy.txt).

Конфигурация: [Operator sudoers](../configs/sudoers/ubuntu-ops-operator).

Осталось проверить реальный перезапуск API и
недоступность изменения файлов службы и исполняемого
кода для оператора.
