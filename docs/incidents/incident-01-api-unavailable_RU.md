# INC-01 — Недоступность HTTP API

## Статус
Устранён (контролируемый инцидент LAB 01).

## Окружение
- Сервер: ubuntu-ops-01
- Сервис: ubuntu-ops-api.service
- Endpoint: http://127.0.0.1:8080/health
- Дата инцидента: 2026-10-14 (UTC)

## Симптомы
- systemctl is-active вернул inactive.
- HTTP-проверка завершилась с кодом curl 7.
- Подключение к 127.0.0.1:8080 было отклонено.

## Диагностика
systemctl status показал inactive (dead).

В журнале в 16:09:15 UTC зафиксировано:
- Начало остановки ubuntu-ops-api.service
- Успешная деактивация сервиса
- Завершение остановки сервиса

Процесс получил сигнал SIGTERM.

## Первопричина (Root Cause)
Сервис был намеренно остановлен командой
systemctl stop в рамках учебного инцидента.

Restart=on-failure не перезапускает сервис
после намеренной административной остановки.

## Устранение
Сервис восстановлен командой:

sudo systemctl start ubuntu-ops-api.service

## Проверка восстановления
- Состояние сервиса: active
- HTTP-проверка: успешно
- Ответ API:
  {"status": "ok", "service": "ubuntu-ops-api"}

## Профилактика и выводы
- Ограничивать права на остановку сервисов.
- Выполнять регулярные проверки доступности.
- Рассмотреть оповещения при недоступности сервиса.
- Отличать административную остановку от аварии.
- Не полагаться только на Restart=on-failure.
