## 12. Реагирование на инциденты и анализ первопричин

Дата проверки: 2026-10-14.

В лабораторном окружении воспроизведены,
диагностированы, устранены и задокументированы
три контролируемых инцидента.

### INC-01 — Недоступность HTTP API

Сценарий:
Служба ubuntu-ops-api.service намеренно остановлена.

Симптомы:
- Состояние службы: inactive (dead)
- HTTP-соединение отклоняется
- Код завершения curl: 7

Первопричина:
Явная административная остановка через systemctl stop.

Устранение:
Служба запущена командой systemctl start.

Проверка:
- Служба вернулась в состояние active
- HTTP /health вернул status ok
- Результат: PASS

Намеренная остановка отличается от аварийного
завершения процесса. Restart=on-failure не выполняет
автоматический перезапуск после systemctl stop.

RCA: [INC-01 — Недоступность API](incidents/incident-01-api-unavailable_RU.md).

### INC-02 — Ошибка Permission Denied

Сценарий:
Пользователь developer попытался изменить защищённый
конфигурационный файл в каталоге /etc.

Симптомы:
- Permission denied
- Исходная конфигурация осталась неизменной

Первопричина:
Файл принадлежал root:root и имел права 0644.
У developer отсутствовало право записи.

Устранение:
Уполномоченный администратор изменил конфигурацию
через sudo tee без расширения привилегий developer.

Проверка:
- Восстановлено исходное значение mode=production
- Запись от developer по-прежнему запрещена
- Проверка HTTP API успешна
- Временное тестовое окружение удалено
- Результат: PASS

RCA: [INC-02 — Ошибка доступа](incidents/incident-02-permission-denied_RU.md).

Доказательства: [Проверка прав](evidence/incident-02-permissions.txt).

### INC-03 — Нет свободного места на диске

Сценарий:
Попытка записать 70 MiB в изолированную
файловую систему ext4 внутри образа 64 MiB.

Симптомы:
- No space left on device
- Заполненность файловой системы: 100%
- Доступное пространство: 0

Первопричина:
Закончились доступные блоки данных файловой системы.
При этом свободные inode ещё оставались.

Устранение:
Удалён временный тестовый файл fill.bin.

Проверка:
- Заполненность снизилась до 1%
- Освободилось приблизительно 52 MiB
- Контрольная запись успешна: recovery-ok
- SHA256 исходных данных LVM: OK
- Временная loop-файловая система удалена
- Результат: PASS

RCA: [INC-03 — Заполнение диска](incidents/incident-03-disk-full_RU.md).

Доказательства: [Дисковый инцидент](evidence/incident-03-disk-full.txt).
