# INC-02 — Ошибка Permission Denied

## Статус
Устранён (контролируемый инцидент LAB 01).

## Окружение
- Сервер: ubuntu-ops-01
- Пользователь: developer
- Файл: /etc/ubuntu-ops-lab01-incident02/settings.conf
- Дата: 2026-10-14 (UTC)

## Симптомы
Разработчик попытался добавить данные в конфигурацию.
Linux вернул ошибку Permission denied.

## Диагностика
- Владелец файла: root:root
- Права файла: 0644
- Родительские каталоги: 0755
- Developer входит в app-developers, но не в root.
- Исходная конфигурация не изменилась.

## Первопричина (Root Cause)
У developer отсутствовало право записи
в конфигурационный файл, принадлежащий root.

## Устранение
Авторизованный администратор изменил файл
через sudo tee без изменения владельца
и разрешений.

После теста восстановлена исходная
конфигурация mode=production.

## Проверка
- Запись от developer: ЗАПРЕЩЕНА
- Права файла: 0644 root:root
- Конфигурация: mode=production
- HTTP API: PASS
- Временное окружение: удалено

## Выводы
- Диагностировать права через stat и namei.
- Соблюдать принцип минимальных привилегий.
- Не использовать chmod 777 для исправления ошибок.
- Применять авторизованные процедуры развёртывания.
- Проверять целостность конфигурации после изменений.
